# ADR-0002. Spark как единственный движок обработки, Flink не берём

**Статус:** принято · 2026-10-13

## Контекст
В книге примеры на Spark и Flink. Держать два движка на 16 ГБ дорого, а PyFlink неудобен.

## Решение
Batch и streaming делаются на Spark (Structured Streaming). Flink — только если какой-то паттерн
без него не показать. Пока таких нет.

## Последствия
- Один стек, одна конфигурация S3/Delta.
- Где в книге пример на Flink, в отчёте указывается его аналог на Spark.
