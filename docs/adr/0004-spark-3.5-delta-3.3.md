# ADR-0004. Spark 3.5.8 + Delta Lake 3.3.3

**Статус:** принято · 2026-10-13

## Контекст
Доступны Spark 3.5.x и 4.x. Примеры книги написаны под ветку Spark 3.5 / Delta 3.

## Решение
`apache/spark:3.5.8` + Delta 3.3.3 + hadoop-aws 3.3.4 (под Hadoop из образа) + Kafka-коннектор 3.5.8.
Jar'ы зашиты в образ `blog-de/spark:local`.

## Последствия
- Код из книги переносится почти без изменений.
- Python в образе Spark 3.10, генератор работает отдельно на 3.12. Общего кода между ними нет.
